# Security policy

This repository is private. Report vulnerabilities privately through GitHub Security Advisories or a private channel agreed with maintainers; do not open public issues. Include affected revision, impact and reproducible steps without real user data or credentials.

No service or supported version has been released yet. For exposed credentials, revoke and rotate them immediately. Untrusted execution must remain outside API processes and use a separately secured judge boundary; this repository does not claim that a sandbox exists or is secure. Secret scanning, push protection, Dependabot alerts and CodeQL depend on repository/organization settings and plan and are not enabled merely by workflow files.
